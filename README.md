# 인투유학 매뉴얼

인투유학 내부 운영 매뉴얼(매뉴얼 13종 · 상황 카드 89개)을 한 곳에서 찾아보는 홈페이지입니다.
빌드 도구 없이 바로 열리는 정적 사이트입니다. `index.html`을 브라우저로 열거나 정적 호스팅에 그대로 올리면 됩니다.

> **내부용 자료입니다.** 조직도·담당자·정산 기준 등 외부에 공개되면 안 되는 내용이 들어 있습니다.
> 검색엔진 수집은 막아 두었지만(`noindex`), 주소를 아는 사람은 누구나 볼 수 있으므로
> 공개 호스팅에 올릴 때는 반드시 접근 제한(비밀번호·사내 계정 로그인 등)을 함께 걸어 주세요.

## 기능
- 매뉴얼별 화면 전환, 왼쪽 목차(모바일에서는 ☰ 메뉴)
- 상단 검색 — `/` 키로 바로 검색, 상황 카드 코드(예: `CAMP-03`)로도 찾기
- 대응 메시지 **복사** 버튼
- 인쇄 — 처음 화면에서 누르면 전체 매뉴얼 인쇄, 매뉴얼 화면에서 누르면 그 매뉴얼만 인쇄
- 주소로 바로 가기: `#/m03`(캠프 매뉴얼), `#/m03--m03-s4`(그 매뉴얼의 4절), `#/card-CAMP-03`(상황 카드)

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 홈페이지 (빌드 결과물) |
| `assets/css/style.css` | 매뉴얼 원본 스타일 (빌드 때 원본에서 꺼냄) |
| `assets/css/brand.css` | 인투유학 로고 색·첫 화면 배너 (직접 고치는 파일) |
| `assets/js/search-index.js` | 검색 색인 (빌드 때 원본에서 꺼냄) |
| `assets/js/app.js` | 화면 전환·검색·복사·인쇄 동작 (빌드 때 원본에서 꺼냄) |
| `assets/img/` | 로고·파비콘·본문 그림 (빌드 때 생성) |
| `source/manual.html` | 매뉴얼 원본(한 장짜리 HTML) |
| `source/logo-banner.webp` | 로고 원본 |
| `tools/build_site.py` | 원본 → 홈페이지 변환 스크립트 |

## 새 판 매뉴얼 반영하기
1. 새로 받은 매뉴얼 HTML로 `source/manual.html`을 덮어씁니다.
2. 아래를 실행합니다. (Python 3, Pillow 필요: `pip install pillow`)
   ```bash
   python3 tools/build_site.py
   ```
3. `index.html`과 `assets/`가 다시 만들어집니다. 확인 후 커밋합니다.

로고·색은 `assets/css/brand.css`에서, 로고 그림은 `source/logo-banner.webp`를 바꾼 뒤 다시 빌드하면 됩니다.

## 미리 보기

python3 -m http.server 8000
