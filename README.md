# 인투유학 매뉴얼

인투유학 내부 운영 매뉴얼(매뉴얼 13종 · 상황 카드 89개)을 한 곳에서 찾아보는 홈페이지입니다.
빌드 도구 없이 바로 열리는 정적 사이트입니다. `index.html`을 브라우저로 열거나 정적 호스팅에 그대로 올리면 됩니다.

> **내부용 자료입니다.** 조직도·담당자·정산 기준 등 외부에 공개되면 안 되는 내용이 들어 있습니다.
> 배포 사이트는 숫자 4자리 비밀번호로 잠겨 있습니다(아래 「비밀번호 잠금」). 이 GitHub 저장소 자체도 반드시 **비공개(Private)** 로 두세요.

## 비밀번호 잠금 (Vercel)
- `middleware.js`가 서버에서 모든 요청을 먼저 확인합니다. 비밀번호가 맞으면 30일 동안 유지되는 로그인 쿠키를 줍니다.
  로그인 전에는 매뉴얼 본문·검색 색인·그림 파일 어느 것도 내려가지 않습니다(로고·아이콘만 공개).
- 비밀번호는 저장소에 적지 않고 Vercel 프로젝트 환경변수로 둡니다.
  - `SITE_PASSWORD` — 입장 비밀번호
  - `AUTH_SECRET` — 로그인 쿠키 서명용 임의 문자열
- 비밀번호를 바꾸려면 Vercel → 프로젝트 → Settings → Environment Variables에서 `SITE_PASSWORD`를 고치고 다시 배포합니다.
  바꾸는 순간 기존 로그인은 모두 풀립니다.
- 처음 화면 맨 아래 **잠그기**를 누르면 그 기기에서 로그아웃됩니다.
- 로컬 미리 보기(`python3 -m http.server`)에서는 잠금이 동작하지 않습니다.

## 기능
- 매뉴얼별 화면 전환, 왼쪽 목차(모바일에서는 ☰ 메뉴)
- 상단 검색 — `/` 키로 바로 검색, 상황 카드 코드(예: `CAMP-03`)로도 찾기.
  결과는 **매뉴얼별로 묶어** 보여 줍니다: 먼저 어느 매뉴얼에 몇 건 있는지(누르면 그 매뉴얼만), 아래에 매뉴얼마다 해당 절·카드 목록
- 대응 메시지 **복사** 버튼
- 인쇄 — 처음 화면에서 누르면 전체 매뉴얼 인쇄, 매뉴얼 화면에서 누르면 그 매뉴얼만 인쇄
- 주소로 바로 가기: `#/m03`(캠프 매뉴얼), `#/m03--m03-s4`(그 매뉴얼의 4절), `#/card-CAMP-03`(상황 카드)

## 새 판 매뉴얼 반영하기
1. 새로 받은 매뉴얼 HTML로 `source/manual.html`을 덮어씁니다.
2. 아래를 실행합니다. (Python 3, Pillow 필요: `pip install pillow`)
   ```bash
   python3 tools/build_site.py
   ```
3. `index.html`과 `assets/`가 다시 만들어집니다. 확인 후 커밋합니다.

로고·색은 `assets/css/brand.css`에서, 로고 그림은 `source/logo-banner.webp`를 바꾼 뒤 다시 빌드하면 됩니다.

## 인투유학 3단 리플렛
학부모·학생에게 나눠 주는 공식 3단 리플렛입니다. 매뉴얼(01 브랜드·03 캠프·04 유학·07 홍보 표현 규칙·11 자료 제작 기준)의 내용으로 만들었습니다.

| 파일 (`leaflet/`) | 용도 |
|---|---|
| `인투유학_3단리플렛_2026_v3_인쇄용_CMYK.pdf` | **인쇄소에 넘기는 파일** — 303×216mm(재단 여유 3mm 포함), 완성 297×210mm, 2쪽(1쪽 바깥면 · 2쪽 안쪽면) |
| `인투유학_3단리플렛_2026_v3_인쇄용_RGB.pdf` | 같은 판형의 RGB 원본 (RGB 파일을 요청하는 인쇄소·디지털 인쇄용) |
| `인투유학_3단리플렛_2026_v3_사무용_A4.pdf` | 사무실 프린터 양면 인쇄용 (A4 가로 — 양면 설정은 「짧은 쪽으로 넘기기」) |
| `…_바깥면.png`, `…_안쪽면.png` | 카톡·메일로 보여 줄 미리보기 |
| `…_접지선확인.png` | 재단선(점선)과 접는 선(실선) 검수용 |

- **판형·접지:** A4 가로 3단 **말아접기(롤 접지)**. 바깥면은 왼쪽부터 날개 97 · 뒷표지 100 · 앞표지 100mm, 안쪽면은 소개 100 · 캠프 100 · 유학 97mm입니다. 인쇄소에 "A4 3단 말아접기, 안쪽으로 접혀 들어가는 면 97mm"라고 알려 주세요.

- **QR 두 개 (뒷표지):** 상담 문의 칸의 큰 QR은 상담 신청 링크 `https://intoeduad.intoedu0309.workers.dev/apply`(행정 홈페이지에 기록됨), 아래 작은 QR은 웹사이트입니다. 링크가 바뀌면 QR을 새로 만들어야 하므로(`source/leaflet/img/qr-apply.svg`) 인쇄 전에 주소를 확정합니다.

  ```bash
  node tools/build_leaflet.js
  ```
  필요한 것: Node 18+, Playwright(Chromium). 선택: Ghostscript(`gs`, CMYK 변환), Python `pypdf`(재단 상자 지정). 없으면 해당 단계만 건너뜁니다.
